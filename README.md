# Alumbrado de Medellín — Multi Travel

App de venta del plan navideño de Multi Travel (RNT 245488). Hecha por Vibras Positivas HM.

## Publicar
1. Cree el repo **alumbrado-medellin** en github.com/haroldco45 (el nombre exacto importa para la imagen de vista previa).
2. Suba todos estos archivos a la raíz.
3. Settings → Pages → Branch: main / root → Save.
4. Queda en https://haroldco45.github.io/alumbrado-medellin/

## Código de asesor
- Todas las reservas por WhatsApp llevan el código **VIBRAS-HM**.
- Para otro asesor: `...alumbrado-medellin/?ref=CODIGO`
- Si WhatsApp muestra la vista previa vieja, comparta con `?v=2` al final.
